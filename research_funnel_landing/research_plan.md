# Plan de investigación: Funnels de venta y landing pages

## Pregunta principal
¿Cuáles son los mejores repositorios de GitHub para crear funnels de venta, y cuáles son las mejores prácticas para construir una landing page de alta conversión (punto de partida del funnel)?

## Subtemas

### 1. Repositorios de GitHub para funnels de venta
- Herramientas open-source tipo "funnel builder" (alternativas a ClickFunnels: p. ej. builders de páginas, form builders, automatización de marketing).
- Plantillas/boilerplates de landing pages y funnels (Next.js, Astro, HTML/Tailwind).
- Analítica de funnel open source (PostHog, Matomo, Plausible, etc.).
- Esperado: lista de 8-15 repos con estrellas, stack, licencia y para qué sirve cada uno.

### 2. Mejores prácticas de estructura y copy de una landing page
- Anatomía de una landing de alta conversión: hero, propuesta de valor, prueba social, CTA, objeciones, FAQ.
- Principios de copywriting y jerarquía de mensaje.
- Fuentes: guías reconocidas (Julian Shapiro, Unbounce, CXL, marketingexamples, etc.).

### 3. Mejores prácticas técnicas y de conversión (CRO)
- Rendimiento (Core Web Vitals), móvil-primero, formularios, A/B testing.
- Métricas y benchmarks de conversión; errores comunes.

## Síntesis
Informe final con: (a) tabla de repos recomendados, (b) blueprint sección por sección de la landing, (c) checklist técnico/CRO, aplicado al contexto del sitio CreativeMk (sitio estático desplegado en Cloudflare).
